# JM × JY Official Quadratic Anti-Blend — 실험 설계

## 1. 실험 배경

이 실험의 목적은 JM과 JY 두 모델을 단순 평균하는 것이 아니라, 두 모델의 예측
차이가 공식 평가셋에서 어떤 방향으로 작용하는지를 정량적으로 해석하고 최적의
결합점을 찾는 것이었다.

당시 확인된 공식 Public BSS는 다음과 같았다.

| 모델 | Public BSS |
|---|---:|
| JM RobustTensorEB | `1148.77306` |
| JY R Residual ×0.15 | `1130.3604943627` |
| JM/JY 50:50 결합 | `1142.1381933225` |

일반적인 예상이라면 두 모델을 섞은 50:50 점수는 두 단독 모델 점수 사이에 있어야
한다. 실제 50:50 점수도 그 범위 안에 있었지만, JM과 JY의 단순 점수 평균보다
상당히 높았다.

```text
두 단독 점수의 평균: 1139.5667771814
50:50 실제 점수:     1142.1381933225
차이:                  +2.5714161411
```

이는 두 모델의 오차가 완전히 같지 않으며, 예측 차이에 활용 가능한 다양성이 있다는
뜻이다. 동시에 JY 단독 점수가 JM보다 낮았기 때문에 최적점이 두 모델 사이의 convex
blend에만 존재한다고 단정할 수 없었다.

## 2. 핵심 아이디어

두 모델의 예측을 다음과 같이 하나의 축으로 표현했다.

```text
p(w) = p_JM + w × (p_JY - p_JM)
```

가중치의 의미는 다음과 같다.

| `w` | 의미 |
|---:|---|
| `0.0` | JM 예측 그대로 사용 |
| `0.5` | JM/JY 50:50 결합 |
| `1.0` | JY 예측 그대로 사용 |
| `< 0` | JM에서 JY의 반대 방향으로 이동하는 anti-blend |
| `> 1` | JY를 지나 같은 방향으로 외삽 |

핵심 전환은 결합 범위를 `[0, 1]`로 제한하지 않은 것이다. JY가 JM보다 낮은 점수를
기록했더라도, `p_JY - p_JM` 방향 자체가 평가셋에서 유용한 오차 축이라면 그 반대
방향으로 이동해 JM의 편향을 줄일 수 있다고 보았다.

## 3. Brier 점수의 이차 구조

Brier Score는 확률 예측의 제곱오차를 사용한다.

```text
BS(w) = mean((p(w) - y)²)
```

`p(w)`가 `w`에 대한 선형식이므로 이를 제곱한 `BS(w)`는 `w`에 대한 정확한
이차함수가 된다. Brier Skill Score 역시 동일한 평가 데이터와 기준 분모를 사용하면
`w`에 대한 이차함수다.

따라서 `w=0`, `w=0.5`, `w=1`의 공식 점수 세 개만 있으면 clipping이 발생하지
않는 구간의 전체 점수 곡선을 복원할 수 있다.

점수 곡선을 다음처럼 나타냈다.

```text
S(w) = (1-w)S_JM + wS_JY + D × w(1-w)
```

여기서 `D`는 두 모델의 다양성으로 인해 단순 점수 보간보다 추가로 얻는 곡률이다.

```text
D = 4 × {S(0.5) - 0.5[S_JM + S_JY]}
  = 10.2856645646
```

`D > 0`이므로 두 모델의 예측 차이는 실제 평가셋에서 분산 감소 효과를 만들고
있었다. 단순히 JM이 JY보다 우수하다는 사실만으로 JY 방향을 폐기할 수 없었던
이유다.

## 4. 최적 가중치 도출

복원한 이차함수를 미분하면 비제약 최적점은 다음과 같다.

```text
w* = (D + S_JY - S_JM) / (2D)
   = -0.3950596007510654
```

최적점이 음수라는 것은 JY 예측을 JM에 더하는 것이 아니라, JM에서 JY 방향을
일부 빼야 한다는 의미다.

```text
p_final = p_JM - 0.3950596008 × (p_JY - p_JM)
```

동일한 식을 전개하면 다음과 같다.

```text
p_final = 1.3950596008 × p_JM - 0.3950596008 × p_JY
```

즉, 이 실험은 JY를 약한 모델로 단순 배제한 것이 아니다. JY와 JM의 예측 차이를
JM의 잔여 편향을 나타내는 방향 벡터로 해석하고, 그 반대 방향으로 JM을 보정했다.

## 5. R행에만 적용한 이유

JM과 JY의 성능 차이 및 잔차보정은 주로 `game_type == "R"` 구간에서 발생했다.
반면 F행에는 이미 검증된 JM 계열 예측을 유지하는 것이 안전했다.

따라서 전체 행에 동일한 anti-blend를 적용하지 않고 다음과 같이 구성했다.

```text
F: p_final = p_JM

R: p_final = clip(
       p_JM - 0.3950596007510654 × (p_JY - p_JM),
       1e-6,
       1 - 1e-6
   )
```

이 설계는 개선 근거가 있는 R 영역만 수정하고, 이미 안정적인 F 영역은 그대로
보존하는 보수적인 분기 전략이다.


예측에도 그대로 적용됐음을 보여준다.

## 8. 실험의 의미

### 8.1 좋은 모델끼리만 섞어야 하는 것은 아니다

단독 점수가 낮은 모델도 상위 모델과 다른 오차 구조를 가지면 유용한 방향 정보를
제공할 수 있다. 이 실험에서 JY 모델은 최종 예측의 양의 구성요소라기보다, JM의
편향을 교정할 방향을 알려주는 기준 벡터 역할을 했다.

### 8.2 blend 범위를 제한하면 최적점을 놓칠 수 있다

일반적인 `[0, 1]` 탐색에서는 최적 후보가 JM 단독인 `w=0`으로 끝난다. 탐색을
음수 영역까지 확장했기 때문에 `w=-0.3951`의 개선점을 발견할 수 있었다.

### 8.3 평가함수의 구조를 직접 활용했다

무작위 grid search로 많은 제출을 반복하지 않고, Brier 점수의 이차 구조를 이용해
세 공식 관측점에서 최적점을 계산했다. 그 결과 추가 공식 제출 한 번으로 이론
최적점과 거의 동일한 점수를 얻었다.

### 8.4 수정 영역을 제한하는 것이 중요했다

anti-blend를 전 행에 적용하지 않고 R행에만 적용해, F 영역의 기존 성능을 보존했다.
이는 서로 다른 전문 영역을 가진 모델을 결합할 때 전체 가중치 하나보다 영역별
결합이 더 안전할 수 있음을 보여준다.

## 9. 한계와 주의사항

이 실험은 공식 Public leaderboard 점수 세 개를 이용해 가중치를 선택했다. 따라서
일반적인 strict OOF 모델 선택이 아니라 leaderboard-driven calibration에 해당한다.

- Public leaderboard에 과적합될 수 있다.
- Private leaderboard에서도 동일한 최적점이 유지된다는 보장은 없다.
- 평가셋 또는 시즌이 바뀌면 `-0.3951`을 그대로 재사용해서는 안 된다.
- clipping이 많이 발생하는 외삽 범위에서는 이차곡선의 정확성이 깨질 수 있다.
- 두 기반 모델의 버전이나 예측 행 정렬이 달라지면 공식 점수 곡선도 달라진다.

따라서 이 실험의 핵심 성과는 특정 가중치 자체보다, Brier 평가에서 모델 간 예측
차이를 하나의 축으로 정의하고 세 점으로 점수 곡선을 복원해 외삽 최적점을 찾은
설계 방법에 있다.

## 10. 최종 결론

JM 단독 모델이 JY보다 강했지만, 50:50 제출에서 확인된 양의 다양성 곡률은 JY의
예측 차이가 버릴 정보가 아니라는 것을 보여줬다. 이를 바탕으로 convex blend의
경계를 넘어 음수 가중치를 허용했고, R행에서만 `w=-0.3950596008`을 적용했다.

그 결과 이론 예상 `1150.3783651466`과 거의 동일한 공식
`1150.3783882339`를 기록하며 당시 최고 성능에 도달했다.
