# 운영진 답변에 따른 데이터 사용 원칙

사용자가 제공한 2026-08-07 및 2026-08-10 운영진 답변을 기준으로 정리했습니다.

## 허용된 사항

1. 학습 기간 데이터에서 `pitcher_id`와 `pitcher_trackman_id`의 대응 관계 추정
2. 추정 대응을 이용한 투구 시점 이전 시즌 Trackman 투수 요약 피처 사용
3. `train.csv` 안에서 같은 투수의 미래 행을 참조해 현재 학습 target 세분화

## 이 프로젝트의 적용

- 다음 행의 `asof_pitcher_n`이 정확히 1 증가할 때만 누적률 차분 라벨을 사용
- 차분으로 복원한 success가 공식 target과 일치하는지 전체 데이터에서 검증
- middle/reverse는 누적률 차분, wild는 나머지 실패로 정의
- Trackman은 매핑 신뢰도 검증 후 고신뢰 투수만 사용
- 학습 행의 Trackman 피처는 해당 행 시즌보다 이전 시즌만 집계
- 2025 평가 행에는 2019~2024 고정 집계만 사용
- 평가 `test.csv` 내부 행을 이용한 집계·빈도·rolling은 계속 금지

## 2026-08-10 로컬 검증 결과

- subtype 복원 가능: 1,473,508 / 1,475,092행 (99.8926%)
- 같은 차분 방식으로 복원한 success와 `control_success` 일치율: 100%
- reverse 또는 middle 차분값이 1인 행의 실패율: 100%
- 전체 실패 중 reverse/middle/ball 중 하나 이상 표시된 비율: 95.1237%
- ball만 표시된 행의 실패율: 40.9009%
