# LG Aimers 9기 Phase 2 — 투수 제구 성공 확률 예측 프로젝트 회고

> 프로젝트 기간: 2026년 8월
> 최종 최고 Public BSS: **1150.3783882339**
> 문제 유형: 야구 투구 단위 이진 확률 예측 / 시계열·도메인 이동 / Brier Skill Score 최적화

## 1. 프로젝트 한 줄 요약

공식 경기 기록과 Trackman 이력만을 사용해 각 투구의 `control_success` 확률을 예측하고, 시간순 검증·계층적 사전확률·잔차 모델·상황별 전문가·앙상블 및 Brier 점수의 이차 구조를 활용해 Public BSS를 **703.94에서 1150.38까지 개선한 프로젝트**다.

## 2. 프로젝트 배경과 목표

LG Aimers 9기 온라인 해커톤 Phase 2의 과제는 평가 데이터의 각 투구에 대해 제구 성공 확률을 예측하는 것이었다. 단순한 성공/실패 분류가 아니라 확률의 정확도를 평가하는 문제였으며, 공식 평가지표는 Brier Score를 기준 분산으로 정규화한 Brier Skill Score였다.

```text
BSS = 100000 × (1 − Brier / [ȳ(1−ȳ)])
Brier = mean((prediction − target)²)
```

팀의 실질적인 목표는 Phase 3 진출 가능권으로 판단한 1200점 이상이었다. 최종적으로 1200에는 도달하지 못했지만, 반복 실험 과정에서 검증 체계를 전면 수정하고 실제 리더보드 점수의 수학적 구조를 활용해 **최종 1150.3784점**을 기록했다.

## 3. 데이터와 문제의 핵심 난점

### 사용 데이터

- 공식 `train.csv`: 투구 상황, 투수·타자 정보, 누적 성공률 및 정답
- 공식 `test.csv`: 행별 추론 입력
- 공식 `trackman_history.csv`: 구속, 회전, 무브먼트, 릴리스 등 과거 물리 정보
- 외부 데이터와 외부 API는 사용하지 않음

### 핵심 난점

1. **시간 이동**
   같은 시즌 안의 랜덤 검증 성능이 다음 시즌 성능으로 이어지지 않았다. 특히 2023년은 모델 신호가 비정상적으로 약한 저신호 체제였고, 2022·2024년과 모델 반응이 크게 달랐다.

2. **평가 데이터 행 독립성 규칙**
   한 test 행의 예측에는 그 행 자체와 공식 train에서 미리 만든 정보만 사용할 수 있었다. test의 다른 행을 이용한 선수별 집계, rolling, lag, 평균, 빈도, 순위, 분포 보정은 모두 금지됐다.

3. **약한 행 단위 신호**
   제구 성공에는 투수의 당일 컨디션과 경기 내 잠재 상태가 크게 작용하지만, 규칙상 test의 이전 투구를 이용해 이를 복원할 수 없었다. 관측 가능한 행 단위 변수만으로 얻을 수 있는 추가 잔차 신호가 매우 작았다.

4. **로컬 점수와 리더보드 전이 불일치**
   2024 로컬에서 큰 개선을 보인 후보가 실제 2025 평가에서는 하락하는 사례가 반복됐다. 따라서 단일 연도 점수나 서로 다른 모델 계열의 로컬→사이트 환산은 신뢰할 수 없었다.

## 4. 규칙 준수 설계

모든 최종 추론은 다음 원칙으로 설계했다.

- test 각 행을 독립적으로 처리
- 현재 행의 입력값으로만 파생변수 생성
- 선수·상황 통계는 공식 train만으로 사전 계산해 고정
- Trackman 정보는 해당 투구보다 이전 시즌의 공식 기록만 사용
- test 내부의 다른 행을 이용한 누적·rolling·lag·분포 보정 금지
- `row_id`를 예측 신호로 사용하지 않고 결과 정렬에만 사용
- 단일 행, 전체 test, 셔플된 test에서 동일 행의 예측이 같은지 자동 검사

학습 데이터에서는 동일 투수의 다음 누적값과 현재 누적값의 차이를 이용해 실패 유형 보조 타깃을 복원했다. 전체 학습 행의 99.89%에서 복원이 가능했고, 같은 방식으로 복원한 성공 라벨은 공식 `control_success`와 100% 일치했다. 이 보조 타깃은 학습 과정에만 사용했다.

## 5. 피처 엔지니어링

### 기본 행 단위 피처

- 볼·스트라이크 카운트와 `count_state`
- 투수·타자 손잡이 및 좌우 매치업
- 아웃카운트, 이닝, 주자 상황, 점수 차
- 2스트라이크, 3볼, 풀카운트 등 압박 상황
- 득점권·만루·경기 후반·레버리지 파생값
- 투수 커리어 및 최근 1/3/5경기 성공률
- 누적 표본 수와 성공률의 불확실성
- 최근 성공률과 커리어 성공률의 차이 및 기울기

### 계층적 사전확률

표본이 적은 선수의 누적 성공률을 그대로 사용하면 분산이 커지므로, 리그 평균과 최근 성적을 이용해 부분 풀링했다. 투수 커리어율, 최근 시즌 상태, 표본 신뢰도를 조합해 안정적인 기본 확률을 만들고 모델은 주로 이 기본 확률의 잔차를 학습했다.

### Trackman 피처

공식 학습 기간의 출현 패턴으로 `pitcher_id`와 Trackman ID의 대응을 추정하고, 직전 시즌까지의 구속·회전·무브먼트·릴리스 안정성 등을 고정 프로필로 만들었다. 추론 중 원본 평가 행끼리 집계하지 않고 사전 생성된 train 자산을 조회했다.

### 실패 유형 보조 타깃

누적률 차분으로 `middle`, `reverse` 실패 유형을 복원하고, 나머지 실패를 operational `wild`로 정의했다. 이를 세 개의 보조 risk expert가 학습하도록 구성해 단일 성공 라벨보다 실패 구조를 세분화하려 했다.

## 6. 모델 구조의 발전 과정

### 6.1 초기 베이스라인과 첫 실패

초기에는 HistGradientBoosting, Deep MLP, Trackman CatBoost, 실패 유형 전문가와 같은 여러 모델의 random OOF meta-controller를 사용했다. 같은 시즌 랜덤 OOF는 좋아 보였지만 첫 주요 제출은 **703.9432점**에 그쳤다.

이 실패를 통해 랜덤 분할이 시간 이동을 심각하게 과소평가한다는 사실을 확인했고, 이후 검증을 시간순 forward 방식으로 변경했다.

### 6.2 계층 베이스 + CatBoost 잔차 모델

다음 구조에서는 복잡한 end-to-end 모델 대신 다음과 같이 역할을 분리했다.

```text
계층적 성공확률 base
  + recency-weighted CatBoost residual ensemble
  + middle / wild / reverse 실패유형 expert
  + 얕은 adaptive gate
```

이 구조는 1070.35점의 hierarchical stack에서 시작해 adaptive gate를 추가하면서 **1088.53점**까지 상승했다. 심리 latent, FiLM, split prior, minimax 등 복잡한 보정을 추가했지만 대부분 개선이 없거나 오히려 하락했다.

### 6.3 평가함수 기반 채널 앙상블

Brier 점수는 예측 벡터의 선형 결합 가중치에 대해 정확한 이차함수가 된다.

```text
S(αA + (1−α)B)
= αS(A) + (1−α)S(B) + α(1−α)G
```

서로 다른 보정 채널의 실제 제출 점수와 중간점 점수를 이용해 곡률을 측정하고, 낮은 단독 점수의 채널도 반대 방향으로 빼는 signed blend를 구성했다. 그 결과:

- `blend50`: 1098.38
- 채널 최적화: 1102.85
- 6-seed ensemble: 1108.95
- 전역 평균 편향 보정: **1119.22**

특히 +0.03 상수 이동 프로브를 이용해 예측 평균이 실제보다 약 0.0052 낮다는 것을 역산했고, 고정 shift를 적용해 약 10.27점을 회수했다. 이후에는 반복적인 상수 프로빙의 규정 위험을 고려해 같은 방식을 확장하지 않았다.

### 6.4 리그 분리와 R 전용 신호

정규리그와 퓨처스리그의 생성과정이 다르다고 보고 F 전용 residual expert를 도입했다.

- F expert: 1122.26
- F regime: 1126.45
- 보정 강도 0.75: 1126.87
- R 전용 residual: 1127.89
- 팀 단위 R residual: 1130.36
- command signature + token dual: **1135.55**

같은 리그 내부를 지나치게 세분화한 thin-history, 선발/불펜, 불펜×카운트 모델은 표본 손실이 더 커서 실패했다. 반면 R/F 분리는 실제 생성과정의 차이가 충분히 커서 제한적으로 유효했다.

### 6.5 Tensor Empirical Bayes 기준 모델

최종 단계에서는 투수와 상황의 고차원 조합을 그대로 학습시키기보다, gap·pocket·투수 상태를 저자유도 tensor cell로 구성하고 Empirical Bayes shrinkage를 적용한 기준 모델이 가장 강했다.

- Tensor-EB 기본: 1143.97
- scale 0.55: 1146.40
- scale 0.58: 1146.78
- 투수 floor gate 0.25 기준 모델: **1148.7731**

이 결과는 모델 용량을 키우는 것보다 구조적으로 의미 있는 셀을 만들고 작은 셀을 강하게 수축하는 편이 다음 시즌 전이에 유리하다는 것을 보여줬다.

### 6.6 최종 Official Quadratic Anti-Blend

최고 Tensor-EB 모델 A와, 점수는 더 낮지만 다른 오차 방향을 가진 R residual 모델 B를 다음 축으로 표현했다.

```text
p(w) = p_A + w × (p_B − p_A)
```

공식 점수 세 점 `w=0`, `w=0.5`, `w=1`을 이용해 Brier 이차곡선을 복원했다. 비제약 최적점은 `w=-0.3950596008`이었고, 개선 근거가 있던 R행에만 anti-blend를 적용했다.

```text
F행: p_final = p_A
R행: p_final = 1.3950596008 × p_A − 0.3950596008 × p_B
```

- 이론 예상 점수: 1150.3783651466
- 실제 Public 점수: **1150.3783882339**
- 예상 오차: 약 0.000023점

이 실험은 최종 최고점을 만들었고, 단독 점수가 낮은 모델도 상위 모델의 오차 방향을 설명한다면 음수 가중치의 보정 축으로 활용할 수 있음을 확인했다.

## 8. 점수 구조 분석

점수는 다음과 같이 해석했다.

```text
S = 2C − W − B
C = K × Cov(p, y)        # 정답과 함께 움직이는 정보량
W = K × Var(p)           # 예측 분산 비용
B = K × bias²            # 평균 편향 비용
```

초기에는 seed 평균과 전역 shift로 `W`와 `B`의 손실을 상당 부분 제거할 수 있었다. 그러나 1135점 이후 기준 모델은 이미 아핀 보정에 가까웠다. 1150에서 1200으로 가려면 단순 확률 확대·축소나 평균 이동이 아니라, `W`를 크게 늘리지 않으면서 `C`를 약 25점 이상 추가해야 했다.

마지막 진단에서 2024 기준 전역 affine 보정 이득은 약 +2.22점뿐이었다. 즉 현재 예측은 전체적으로는 이미 잘 보정되어 있었고, 남은 개선은 새로운 정답 상관 신호에서만 가능했다.

상황별 같은 연도 oracle 보정은 `count×outs×runners`에서 최대 +36.75점을 보였지만, 이전 연도에서 학습해 다음 연도로 넘기면 count 보정은 약 +0.8점에 그쳤고 더 세밀한 pressure 보정은 음수가 됐다. 개선 여지는 존재했지만 그 방향이 시즌 간 안정적으로 유지되지 않았다.

## 9. 실패한 접근과 원인

### 과적합 또는 시즌 전이 실패

- 심리 latent, FiLM, Transformer, context token
- 고차원 상황별 prior와 residual lookup
- RandomForest, HGB, LightGBM 독립 채널
- Group DRO, IRM, adversarial reweighting
- 상태공간 모델, GRU, masked pretraining, DCN 계열
- 투수·타자 graph/SVD 및 retrieval 모델
- Trackman direct head, robust/expectile/paired loss
- pressure, win expectancy, pitch mix 고차 상호작용

대부분 2024 한 시즌에서는 개선됐지만 2023 또는 다른 forward 시즌에서 부호가 반전됐다. 특히 2023년에는 `C/W` 최적 기울기가 여러 count 구간에서 0.02~0.51 수준으로 붕괴한 반면 2022·2024는 대체로 1 근처였다. 이는 특정 피처 하나의 누락이 아니라 시즌 전체의 신호 강도가 달라지는 regime 문제였다.

### 모델 용량 증가 실패

- seed 6개에서 24개로 확대: 실제 점수 하락
- CatBoost iteration·depth 확대: early stopping 이후 악화
- 더 많은 채널을 탐색해 선택: 홀드아웃 성능 감소

복잡도를 높일수록 train 시즌의 선수·상황 조합을 더 잘 외웠지만 다음 시즌으로 전달되는 정보량은 늘지 않았다.

### 공격적 앙상블 실패

- wide hedge: 로컬 예상 1233~1375, 실제 **1095.37**
- leaderboard-fitted affine: 실제 **1121.18**
- 공격적 Tensor reconstruction: 실제 **1123.41**
- hand correction 강화: 기준 1150에서 **1119.12**로 하락

이 사례들로 서로 다른 모델 방향 사이의 로컬 covariance를 사이트 점수로 직접 환산하는 방식을 폐기했다. 이후 새 방향의 사이트 예상치는 원칙적으로 `UNKNOWN`으로 두고, 동일한 고정 방향의 검증된 strength 보간만 제한적으로 수치화했다.

## 10. 최종적으로 1200에 도달하지 못한 이유

1200에 필요한 것은 현재 대비 약 2.1%의 점수 상승이 아니라, 예측-정답 상관계수 기준 약 2%대의 추가 개선이었다. 숫자상 작아 보이지만 이미 캘리브레이션 손실을 거의 제거한 상태에서는 전부 새로운 정보량이어야 했다.

관측 가능한 행 단위 피처의 기준 모델 잔차 상관은 매우 작았다. 안정적으로 부호가 유지된 수치 피처도 절대 상관이 약 0.002 수준이었고, count·손잡이·주자·압박 상태의 세분 보정은 같은 연도 oracle에서는 커 보였지만 다음 시즌으로 전달되지 않았다.

가장 큰 미관측 요인은 투수의 **당일 컨디션, 경기 내 누적 피로, 직전 투구 결과에 따른 심리 및 command state**로 추정됐다. 하지만 이를 test의 다른 행에서 복원하는 것은 대회 규칙 위반이었다. 현재 행 하나와 과거 공식 train만으로는 이 잠재 상태를 충분히 식별할 수 없었다.

또한 최종 1150 기준 모델과 정확히 동일한 strict-forward OOF 벡터를 일찍 확보하지 못해, 후반 후보 상당수를 1135 기준 OOF에 비교해야 했던 평가 공백도 있었다. 결과적으로 로컬 개선이 1150 기준에서도 독립적인 새 신호인지 정확히 판별하는 데 한계가 생겼다.

## 11. 잘한 점

- 첫 대형 실패 후 random OOF를 폐기하고 시간순 검증으로 전환
- 확률 모델을 계층 base, residual, subtype expert, gate로 역할 분리
- 공식 데이터만 사용하고 test 행 독립성을 자동 검증
- Brier 점수의 이차 구조를 이용해 제출 한 번으로 최적 anti-blend를 정확히 계산
- 실패한 실험도 점수·원인·재현 자산과 함께 기록
- 로컬 고득점이 실제 고득점을 의미하지 않는다는 사실을 실측으로 교정
- 최종 최고점의 예상과 실제를 0.000023점 오차로 재현

## 12. 아쉬운 점과 개선 방향

### 평가 체계

최종 기준 모델이 바뀔 때마다 그 모델 자체의 2022·2023·2024 strict-forward OOF를 즉시 생성했어야 한다. 다음 프로젝트에서는 모든 모델이 공통 OOF 인터페이스를 구현하고, 후보는 항상 현재 최고 기준 모델과 동일 행에서 비교하도록 해야 한다.

### 실험 관리

후반에 제출 기회가 부족해지면서 1200이라는 목표 점수에 맞춘 공격적 후보가 늘었다. 목표 점수에서 역으로 모델을 선택하기보다, 사전에 정의한 안정성 gate를 통과한 후보만 제출하는 원칙을 더 일찍 고정할 필요가 있다.

### 모델링

다음 시도에서는 고차원 모델 추가보다 다음 두 방향이 우선이다.

1. 이전 시즌 Trackman으로 예측한 command reliability를 저자유도 latent state로 만들고, 상황에 따라 기존 선수 신호의 신뢰도만 조절하는 모델
2. 시즌별 신호 강도 차이를 직접 추정하는 hierarchical random-slope 또는 regime reliability 모델

단, 이 모델들도 반드시 과거 시즌 학습 → 다음 시즌 평가의 nested forward 검증을 거쳐야 한다.

## 13. 재사용 가능한 핵심 교훈

1. 시계열 문제에서 같은 시즌 random OOF는 실제 배포 성능을 크게 과대평가할 수 있다.
2. 확률 점수는 정보량, 분산, 평균 편향으로 분해해서 봐야 한다.
3. 강한 모델이 이미 잘 보정됐다면 calibration보다 독립적인 공분산 신호가 중요하다.
4. 낮은 점수의 모델도 오차 방향이 다르면 anti-blend 축으로 유용할 수 있다.
5. 고차원 상황 보정의 같은 연도 oracle gain은 다음 시즌 전이를 보장하지 않는다.
6. 모델 용량보다 생성과정의 올바른 분리와 적절한 shrinkage가 더 중요할 수 있다.
7. 실제 실패한 리더보드 방향은 매력적인 로컬 결과보다 강한 반증이다.
8. 대회 규칙은 마지막 검수 항목이 아니라 피처와 검증 설계의 시작점이어야 한다.

## 14. 최종 결과

최종 최고 제출은 Tensor Empirical Bayes 기준 모델과 R 전용 residual 모델의 차이를 Brier 이차식으로 분석해 만든 Official Quadratic Anti-Blend였다.

```text
최종 Public BSS: 1150.3783882339
초기 주요 제출:   703.9432300156
총 개선:          +446.4351582183
목표 1200 대비:   -49.6216117661
```

목표 점수에는 도달하지 못했지만, 이 프로젝트를 통해 시간 이동이 큰 확률 예측 문제의 검증법, 계층적 shrinkage, 잔차 전문가 설계, 리더보드 과적합의 위험, Brier 평가함수의 수학적 최적화 방법을 실제 제출 결과로 검증했다.
